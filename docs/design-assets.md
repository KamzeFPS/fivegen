# FiveGen studio artwork

Original assets generated with the built-in image generation tool for the FiveGen redesign. These are editorial artwork and reusable cover designs, not claims about products generated by customers. Inspected before integration. WebP copies preserve the artwork and reduce the three public images from 5.47 MB to 295 KB.

- `public/studio/dunes.webp`: wide cinematic landscape of sculptural burnt-orange and rust sand dunes with a huge smooth black metallic eclipse sphere hovering on the right. A tiny sunlight rim illuminates the sphere. Vast near-black negative space fills the left half for page copy. Luxe surreal campaign art, subtle photographic grain. No text, words, brand lettering, watermarks, UI or frame.
- `public/studio/blue.webp`: a translucent cobalt-blue glass ribbon looping gracefully in black space. Portrait 4:5 editorial sculpture photography, centered loop with black negative space, hard directional studio lighting, sharply lit edges and luminous translucent depth. No text, words, logos, watermarks, UI or frame.
- `public/studio/chrome.webp`: close-up chrome sculptural flower with fluid metallic petals and muted champagne-silver reflections on a black backdrop. Portrait 4:5 high-fashion art photography, tactile metallic detail, controlled sculptural studio lighting, luminous muted reflections and deep black shadows. No text, words, logos, watermarks, UI or frame.

Font: locally served Inter variable Latin, distributed under the SIL Open Font License in `public/fonts/OFL.txt`. Source: Google Fonts (`fonts.googleapis.com` / `fonts.gstatic.com`). Non-Latin text uses the system font fallback.

Brand: the user supplied the FiveGen logo on September 11, 2026. `public/brand/fivegen-original.png` preserves that source, and `fivegen-logo.webp` is a lossless format conversion. The interface displays the original orange monogram in a small white badge using CSS framing, alongside the FiveGen name.
