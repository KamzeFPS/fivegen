## Additional durable Funnel draft state

`0048_funnel_video_draft.sql` adds owner/product-scoped `growth_funnel_drafts`. Owner-only GET includes `videoDraft`; PATCH saves the selected VSL privately with optimistic revision checks and completed/nonvoice upload validation. Copy and video draft saves can finish during Save & continue without touching `growth_funnels` or exposing public media. An explicit publication can include `expectedVideoDraftUpdatedAt`, checked atomically alongside copy and publication revisions. Public getters never include private draft metadata. Existing public snapshots and older clients remain compatible.

## Integration contracts

- `WorkspaceProductSidebar`: optional `activeDestination`, `onDestination(destination)`. Destination union: `overview | content | sales-page | commerce | marketing | customers | settings`. Always use the calling shell's save guard.
- `CreatorLaunchJourney`: `variant="home"` for D1; root routes `sales-page` to the editor and buyer preview to the real simulation/test flow.
- `CreatorIntentPicker`: `onChoose({intent,type,source})`, optional `allFormats`, `onPlan`, `disabled`. Source is upload/manual only.
- `ProductUploadQueue`: `{productId, disabled?, onUploaded(receipt):Promise<boolean>, onBusyChange?}`. Parent must persist attachment before returning true.
- `PageBrandPresets`: `{productId, config, onChange(fullConfig), images?, busy?, onBusyChange?}`. Applying is a draft patch; parent performs ordinary save/version checks.
- `CreatorCollaborators`: `{productId}` owner interface. `/collaborate` lists accepted workspaces, `/collaborate/[id]` drafts within capabilities, `/collaborate/invite/[token]` accepts matching verified identity.
- `useRegisterEditorSave({label,dirty,busy,save:()=>Promise<boolean>,priority?})`: no-op outside a provider. Register draft saves only. Use priority 10 for reviewed context, 20 for active editor, 30 for legacy product. A false/throw stops pending navigation.

## Explicit operating limits

The new migrations must run before using these APIs. Production configuration, actual Stripe/email/AI health, deployment and live purchase tests are not inferred from local success. Private import-review recovery is same-tab and bounded, rather than cloud synchronization. Preset count is bounded at 20, and does not currently include rename/delete management. Collaborator invitation delivery is manual, and drafting authority does not imply publishing or financial authority. No environment files or secrets were read, no live service changed, and no Git commit or push was made by this workstream.
